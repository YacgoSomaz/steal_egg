## 1. 产品定义

| 项 | 内容 |
|---|---|
| 暂定名 | 偷蛋模拟器 / Egg Thief Sim |
| 品类 | 潜行偷窃 + 宠物养成（2D，俯视角） |
| 一句话 | 潜入龙巢偷蛋，带回家孵化养成，用养大的伙伴去偷更贵的蛋 |
| 目标玩家 | 喜欢《鹅作剧》《Thief Simulator》《偷窃手套》这类"做坏事"爽感的休闲玩家；以及图鉴收集党 |
| 单局 | 3-8 分钟 |
| 完整循环 | 15-20 分钟 |
| 目标体量 | 小型独立游戏，原型先行 |

### 成功标准（怎么判断做对了）
- 玩家在第一次"丢光所有蛋"之后，会立刻想再来一次
- 玩家会主动说出"我刚才应该少拿一颗的" —— 说明贪心抉择生效了
- 单局内至少出现 2 次以上的"再拿一颗？"犹豫

## 2. 核心循环

详见 [01-核心循环.md](./01-核心循环.md)。摘要：

```
【内循环·秒级】观察 → 潜行 → 抓蛋 → 负重↑ → 撤离
【外循环·分钟级】选巢 → 出击 → 带回 → 孵化 → 养成 → 伙伴反哺 → 更难的巢
```

三个咬合数值：**警戒值 Alert**（全巢累积）/ **噪音 Noise**（引来守卫）/ **负重 Load**（超线性惩罚）。

## 4. 系统拆解

### S1 玩家控制与潜行
- 输入：WASD 移动 / Shift 切换蹲走-跑步 / E 抓取读条 / Q 放下一颗蛋 / Space 翻滚
- 状态机：`IDLE / SNEAK / RUN / GRABBING / CARRYING_HEAVY / DETECTED / ESCAPED`
- 抓取读条 1.5s，期间不能移动 → 最脆弱时刻，**必须配合守卫背身或伙伴控场**
- 无攻击键（设计决定，见核心循环"明确不做"）

### S2 守卫 AI
- 状态机：`PATROL / SUSPICIOUS / INVESTIGATE / CHASE / RETURN`
- 视野锥：可视多边形（RayCast 遮挡判定），分**核心区（直接发现）**和**边缘区（变 SUSPICIOUS）**
- 听觉：噪音值超过阈值 → `INVESTIGATE` 前往声源
- 追击：Alert 满 → `CHASE`，玩家被抓 → 丢弃全部蛋 + 传送出巢
- 追击中有**脱离机制**：连续 5 秒不在任何守卫视野内 → 回到 PATROL（给高手的逃生窗口）

### S3 警戒值系统
- 全巢共享一个 Alert（0-100），HUD 上是一条常驻的火苗条
- 见核心循环 §3 数值表
- **满值演出**：火苗条烧到顶 → 全屏微红 + 心跳音效 → 龙睁眼

### S4 蛋实体
- 每颗蛋是一个 `EggResource` + 场景实例
- 属性：品种、稀有度、基础售价、重量、活性类型、孵化时长
- 携带时挂在玩家背部的挂点上，有物理晃动
- 掉落：撞墙 / 超重自动掉 → 落地有 30% 摔碎（可升级蛋袋降低）

### S5 巢穴关卡
- 关卡制，非开放世界
- 每个巢固定元素：3-6 蛋位、2-4 守卫、掩体、2 种以上地面材质、1 个出口
- 递进：农场鸡窝（教学）→ 森林鸟巢 → 火山龙巢 → 天空龙巢

### S6 孵化养成
- 孵化槽（初始 1，可升级到 4），现实时间 2-6 分钟
- 成长阶段：蛋 → 幼体 → 亚成体 → 成年
- 属性：`力量 / 敏捷 / 隐匿 / 抗性`，随喂养成长，有随机浮动（不是完全固定，保留惊喜）
- 喂养消耗资源（出击时顺手捡的食材）

### S7 伙伴系统
- 成年后可编入出击队伍（同时最多 1 只）
- 提供被动修正 + 1 个主动技能（有冷却）
- 详见核心循环 §6

### S8 基地与升级
- 孵化槽数量、仓库容量、装备三件套
- 装备：消音靴（噪音 -25%）/ 加固蛋袋（负重上限 +1、摔碎率 -20%）/ 钩爪（可快速撤离一段距离）

### S9 图鉴与解锁
- 品种图鉴（收集驱动）
- 巢穴解锁条件：前一巢"完美撤离"次数 or 拥有特定品种

## 5. 技术方案（Godot 4.7）

### 目录结构
```
egg-thief-sim/
├── addons/mcp4godot/      # MCP 编辑器插件（已接入，端口 9877）
├── scenes/
│   ├── main.tscn
│   ├── player/            # player.tscn, egg_carry.tscn
│   ├── enemies/           # guard.tscn, dragon.tscn
│   ├── nest/              # nest_farm.tscn ...
│   └── base/              # 基地/孵化界面
├── scripts/
│   ├── core/              # GameEvents, GameState, SaveManager
│   ├── player/
│   ├── enemy/
│   ├── egg/               # EggResource, EggEntity
│   └── ui/
├── data/                  # .tres 数据资源（品种表、巢穴配置）
└── docs/
```

### 关键架构决策
1. **数据驱动**：蛋品种、巢穴配置全部用 `Resource`（.tres）定义，调数值不改代码
2. **信号总线**：`GameEvents` autoload 全局单例，解耦系统（如 `alert_changed` / `egg_stolen` / `guard_spotted`）
3. **状态机**：玩家和守卫都用独立的 `StateMachine` 节点，避免写成一坨 if
4. **视野**：守卫用 `RayCast2D` 扇形扫描 + `Area2D` 判定，纯几何计算，不用 NavigationAgent
5. **存档**：`ConfigFile` 或 JSON，存基地状态 + 已养成伙伴 + 图鉴进度

### Autoload 单例
```
GameEvents    # 全局信号总线
GameState     # 当前运行数据（Alert、携带的蛋、资源）
SaveManager   # 存档读写
DataDB        # 品种/巢穴数据表加载
```

### 渲染
- 2D，`gl_compatibility` 渲染器（Web 导出友好）
- CanvasItem 拉伸模式，1280×720 基准分辨率

## 6. 里程碑

> 原则：**先做出能玩的东西，再谈完善。** 每个 Phase 结束都必须是可运行状态。

### Phase 0 — 可玩原型（目标：验证核心手感）
- [ ] 空场景 + 可移动的玩家（WASD + 蹲走/跑步）
- [ ] 一个守卫 + 视野锥 + 巡逻路径
- [ ] 一个蛋 + 抓取读条 + 背在背上
- [ ] Alert 条 + 被抓 → 丢蛋 + 传送出巢
- [ ] 一个出口 + 撤离成功判定
- [ ] **双属性骨架**：隐匿改感知半径、速度改移速（各 Lv1-10，暂时用调试面板调）
- [ ] **天空背景层**：放一条模糊的宇宙龙剪影（哪怕只是占位图）
- **验收**：能在 1 分钟内完整体验"偷一颗蛋跑路"，并且能感受到紧张；抬头能看见天上有东西

### Phase 1 — 循环闭合（目标：验证外循环）
- [ ] 基地场景 + 孵化槽
- [ ] 蛋 → 幼体 → 成年 的成长流程
- [ ] 资源与喂养
- **验收**：偷 3 颗蛋回家，孵出 1 只，能看出来它在长大

### Phase 2 — 反哺（目标：验证留存钩子）
- [ ] 伙伴陪同出击 + 被动修正
- [ ] 影龙/冰龙 2 个品种
- [ ] 第二个巢穴（难度递进）
- **验收**：带伙伴去重偷第一个巢，明显感觉"能多拿一颗了"

### Phase 3 — 内容与打磨
- [ ] 装备三件套 + 基地升级
- [ ] 图鉴 + 存档
- [ ] 音效、粒子、屏幕震动
- [ ] 剩余品种与巢穴

## 7. 美术与音频方向（暂定）

- **风格**：2D 手绘/像素，暖色调巢穴 vs 冷色调夜晚，高对比度（潜行游戏必须一眼看清视野范围）
- **关键可视**：守卫视野锥必须极其清晰（半透明扇形 + 边缘高亮）
- **音频**：噪音必须听得见（脚步声大小直接反馈噪音值），Alert 上升配心跳节奏

---

## 8. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 潜行 AI 手感调不好 | 核心体验崩 | Phase 0 只做 1 个守卫，反复调参到爽为止再扩 |
| 养成系统做成负担 | 玩家觉得肝 | 孵化挂机进行，不做每日任务式强制 |
| 内容量膨胀 | 做不完 | 严守"明确不做"清单，Phase 3 前不做内容 |
| 负重惩罚过重导致挫败 | 玩家不敢贪 | 提供"放下蛋"快捷操作，随时止损 |
