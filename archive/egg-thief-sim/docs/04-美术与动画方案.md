# 偷蛋模拟器 · 美术与动画方案

> 版本 v0.1 ｜ 2026-09-12
> 核心结论：**原型阶段零美术资源**，用程序化动画验证手感；美术等 Phase 2 之后再上。

---

## 零、先说清楚：我不生成图片

我**没有图像生成能力**（图片、视频、3D 模型都不支持，这个能力当前产品不提供）。
所以美术资源只有三条路：你自己画、用现成素材、或者——下面主推的——**先不需要美术**。

这不是退而求其次，这是**正确的开发顺序**：潜行手感没调爽之前，画什么都白画。

## 一、Phase 0-2：程序化动画（零资源）

### 思路
角色就是几个几何体拼的，动画用**代码驱动节点变换**，不依赖任何图片文件。

### 玩家构造（纯节点，无贴图）

```
Player (CharacterBody2D)
├── Body      Polygon2D   椭圆身体
├── Head      Polygon2D   圆头 + 兜帽三角
├── LegL      Polygon2D   矩形
├── LegR      Polygon2D   矩形
└── CarrySlot Node2D      背蛋挂点（蛋实例挂这里）
```

### 走路动画（一行正弦）

```gdscript
# scripts/player/player_anim.gd
extends Node2D

var _t := 0.0

func _process(delta: float) -> void:
    _t += delta * move_speed * 6.0
    var swing := sin(_t) * 0.6          # 腿摆幅（弧度）
    $LegL.rotation = swing
    $LegR.rotation = -swing
    # squash & stretch：走路时身体上下微弹
    $Body.scale.y = 1.0 + sin(_t * 2.0) * 0.06
    $Body.scale.x = 1.0 - sin(_t * 2.0) * 0.04
```

### 背负重时的变化（免费的表现力）

```gdscript
# 蛋越多，身体越往下压 —— 不用画，改 scale 就行
$Body.scale.y = 1.0 - carried_count * 0.04
$Body.rotation = carried_count * 0.02   # 微微前倾
```

**负重的可视化反馈，一行代码就有了。** 这正是程序化的优势：数值和表现直接绑定。

### 视野锥（本来就是程序化的）

守卫视野用 `Polygon2D` 每帧重算顶点，配合 `RayCast2D` 做遮挡。这块无论最终用什么美术风格，都是代码生成，**不需要任何素材**。

### 阶段性收益

| 阶段 | 美术资源需求 |
|---|---|
| Phase 0-2 | **0 个图片文件** |
| 验证内容 | 移动手感、潜行张力、Alert 节奏、负重惩罚、视野判定 |

## 二、动画需求量估算（决定什么时候该上美术）

### 玩家（露脸最多，值得精做）

| 动作 | 帧数 |
|---|---|
| 待机 | 4（呼吸） |
| 蹲走 | 8 |
| 跑步 | 8 |
| 抓取读条 | 6 |
| 负重行走（2-4 颗） | 8 |
| 被抓 | 5 |
| 撤离成功 | 4 |
| **合计** | **约 43 帧** |

### 守卫（数量爆炸，必须复用）

40 种动物 × 3 种状态（巡逻/警觉/追击）× 6 帧 = **720 帧**。这个量不现实。

**分层策略：**

| 对象 | 方案 | 理由 |
|---|---|---|
| **玩家**（1 个，43 帧） | 帧动画，精做 | 全程盯着看，值得 |
| **蛋**（40 种） | 单张静态 + 程序化晃动/发光 | 蛋本来就不该动太多 |
| **守卫/动物**（40 种） | **共用骨架 + 换色换形** | 数量太多，必须复用 |
| **背景/环境**（10 生态） | 分层视差 + 程序化天气 | 粒子和着色器搞定 |
| **宇宙龙** | 单张分层剪影 + 缓慢程序化起伏 | 剪影不需要精细动画 |

**守卫复用方案**：一套 `patrol/alert/chase` 动画骨架，通过改**体型比例、配色、附属部件**（翅膀/尾巴/角）区分 40 个品种。Godot 里用 `Polygon2D` 的顶点参数化就能批量生成。

## 三、正式美术方向建议

### 推荐：扁平几何风

**理由 —— 它跟程序化原型是同一套东西，零返工：**

```
Phase 0 的 ColorRect/Polygon2D 占位  →  直接上色、加描边、加光影  →  正式美术
```

其他优势：
- 不需要绘画功底，你自己就能画
- 40 个品种靠「换形 + 换色」就能批量产出
- 太空巨龙用简单几何剪影反而最有压迫感
- 和"高对比度看清视野锥"的功能需求天然契合

### 备选：像素风
- 免费素材最多（Kenney.nl、itch.io、OpenGameArt 有大量 CC0 资源）
- 但 40 个品种要风格统一，拼素材容易串味
- 像素风的巨龙剪影表现力不如扁平几何

### 不推荐：手绘厚涂 / 3D
- 成本量级不在一个层级，独立项目不建议

## 五、降低美术成本的设计技巧（重要）

**在动手画之前，用设计减少美术需求：**

1. **主角做成"圆滚滚的兜帽小偷"** —— 一个球 + 斗篷，动画只需要整体形变，帧数砍半
2. **蛋做成"会发光的几何体"** —— 蛋本来就该是简洁符号化的，不需要复杂绘制
3. **守卫用剪影** —— 暗色剪影 + 发光眼睛，既省事又更有压迫感（还顺便解决"看清视野"的问题）
4. **环境用色块 + 粒子** —— 火山=橙红渐变+火星粒子，极地=冷蓝+飘雪，全是程序化
5. **宇宙龙永远只露剪影** —— 从始至终不做正面清晰图，既省钱又保持神秘感

> 第 5 条尤其关键：一条**只以剪影示人**的宇宙龙，比任何精细建模都更有压迫感，而且成本几乎为零。

## 六、落地节奏

| 阶段 | 美术工作 |
|---|---|
| Phase 0 | **无**。几何体占位，专注手感 |
| Phase 1 | 无。孵化界面用 UI 控件即可 |
| Phase 2 | 手感验证通过 → **此时才决定美术风格** |
| Phase 3 | 上正式美术：玩家 43 帧 + 40 个蛋的静态图 + 守卫参数化生成 |

**判断标准**：当你能在几何体版本里玩到"手心出汗"了，才值得为它画图。
如果几何体版本都不好玩，画得再好看也没用。
