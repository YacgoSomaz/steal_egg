# 偷蛋模拟器 · 核心循环设计

> 版本 v0.1 ｜ 2026-09-12 ｜ 状态：**待拍板**（见文末开放问题）

---

## 一句话

**潜入龙巢，在「再拿一颗」和「赶紧跑」之间反复抉择，把蛋带回家孵养成伙伴，用伙伴去偷更贵的蛋。**

---

## 一、设计目标（这一条决定所有取舍）

整个游戏只服务一个体验：**让玩家在蛋巢里手心出汗地反复问自己"再拿一颗还是走？"**

凡是强化这个抉择的机制就做，凡是稀释它的就不做。
所以——没有战斗（战斗会让玩家想"打赢"而不是"偷完就跑"），没有血条对拼，没有随机掉落装备。
玩家的敌人只有三样：**守卫的视野、自己身上的负重、以及自己的贪心。**

---

## 二、双循环结构

### 内循环（巢穴内，秒级心跳）

```
观察视野 → 潜行接近 → 抓取蛋 → 负重增加 → 撤离
                ↑                              │
                └──────── 警戒值持续上升 ────────┘
```

四拍循环，每拍都有明确的正负反馈：

| 阶段 | 玩家动作 | 正反馈 | 压力来源 |
|---|---|---|---|
| 观察 | 绕巢、记守卫巡逻路线 | 记住路线 = 效率 | 时间流逝，部分巢有"天亮就关门" |
| 潜行 | 蹲走/冲刺/躲掩体 | 无声接近的爽感 | 视野锥、地面材质（碎石地噪音 ×2） |
| 抓取 | 按住 E 读条 1.5s | 拿到蛋的获得感 | 读条期间不能动，是**最脆弱的时刻** |
| 携带 | 背蛋移动 | 蛋在背上微微发光，看得见的收益 | 负重→移速↓、噪音↑，蛋会**挣扎** |
| 撤离 | 跑向出口 | 逃生成功的释放感 | 警戒值满 → 龙醒 → 追击 |

### 外循环（一次完整出击，分钟级）

```
选巢穴 → 配装/带伙伴 → 出击 → 带回蛋 → 孵化 → 喂养养成 → 变强 → 解锁更难的巢
```

外循环的意义：**让每一次"偷"的收益沉淀成永久成长**，否则偷一百次也只是重复动作。

---

## 三、核心张力：贪心 vs 恐惧（本作的灵魂）

三个数值互相咬合，共同制造那个"再拿一颗"的抉择：

### 1. 警戒值 Alert（0-100，全巢共享）

不是"被看见才涨"，而是**持续累积、永不自动归零**，撤退时仍在涨。

| 行为 | Alert 变化 |
|---|---|
| 站在守卫视野内 | +15 /秒 |
| 视野边缘（半透明区） | +6 /秒 |
| 跑步移动 | +3 /秒 |
| 蹲走移动 | +0.5 /秒 |
| 静立不动 | -2 /秒（唯一的回血方式） |
| **抓取蛋的瞬间** | **+10（一次性，硬惩罚）** |
| 打碎东西 / 蛋掉地上 | +20 |

**关键设计：静立能降警戒，但静立不产收益。** 这就是节奏感的来源——玩家必须主动在"推进"和"平复"之间切换。

### 2. 噪音 Noise（本地，触发守卫调查）

噪音不直接加 Alert，而是**把守卫引过来**。玩家能听见（音效 + 屏幕边缘波纹）。

```
噪音 = 基础移动噪音 × 地面系数 × (1 + 负重系数) × 伙伴修正
```

- 地面：草地 ×0.5 ｜ 石地 ×1.0 ｜ 碎骨地 ×2.0
- 负重：每颗蛋 +35%
- 伙伴修正：影龙 -40%，雷龙 +20%（雷龙会噼啪作响）

### 3. 负重 Load（本作最狠的一条）

**蛋不是背包里的数字，是背上的实体。**

| 携带数 | 移速 | 噪音 | 特殊 |
|---|---|---|---|
| 1 | ×0.95 | +35% | — |
| 2 | ×0.85 | +70% | — |
| 3 | ×0.70 | +105% | 开始有蛋**晃动**，撞到障碍 +15 Alert |
| 4+ | ×0.55 | +140% | 每 8 秒自动掉落 1 颗（掉落 = -20 Alert + 蛋摔碎风险） |

**每多一颗蛋，撤离难度是超线性上升的。** 这就是"再拿一颗"永远让人犹豫的数学基础。

### 4. 人物双属性（与负重对冲）

只有两个属性，**都不加战力，只改变"偷"的额度**（v0.2 新增）：

- **隐匿 Lv1-15** → 守卫感知半径 × (1 − 0.045×(Lv−1))，满级只剩 37%
- **速度 Lv1-15** → 玩家移速 × (1 + 0.04×(Lv−1))，满级 ×1.56

关键在于**速度属性和负重系数是相乘的**：

| 场景 | 有效移速 | 结果 |
|---|---|---|
| 速度 Lv3 + 带 3 颗蛋（×0.70） | 0.76 | 跑不过守卫（0.85）→ 丢光 |
| 速度 Lv7 + 带 3 颗蛋 | 0.87 | 刚好跑得过 |

**点速度 = 能多带一颗蛋。** 属性不是数字变大，是直接兑换成"贪心的额度"——
这让加点变成玩法决策，而不是数值成长。

→ 完整数值见 [03-进阶与兑换体系](./03-进阶与兑换体系.md) §1

## 四、蛋的活性：让"偷"不只是搬箱子

蛋在背上会**闹**，每颗蛋有随机活性，这是单局内的不可预测性来源：

| 蛋类型 | 活性表现 | 应对 |
|---|---|---|
| 火龙蛋 | 每 10s 发烫，+8 Alert | 停在冷区 / 用冰龙伙伴压温 |
| 雷龙蛋 | 随机放电，短暂照亮周围（暴露视野） | 保持移动，避开守卫正面 |
| 影龙蛋 | 会自己轻微挣动，噪音 +20% | 无法消除，只能少带 |
| 石龙蛋 | 极重，负重按 2 颗算 | 值得，因为贵 |
| 凤卵（稀有） | 持续 +2 Alert/秒，全程 | 高风险高回报，抢到就跑 |

**活性让"带哪几颗蛋"变成一个策略选择，而不只是"带几颗"。**

## 五、失败与惩罚（关键：痛但不劝退）

| 结果 | 后果 |
|---|---|
| 警戒值满 → 被抓住 | **丢弃本次携带的全部蛋**，被扔出巢外，**不受伤、不损失已养成的伙伴** |
| 撤离成功 | 全部保留，进入孵化 |
| 完美撤离（全程未被发现） | 额外 +20% 孵化速度奖励（"无痕之偷"） |

**为什么惩罚是"丢蛋"而不是"死亡"：**
偷窃游戏的挫败感来自"白跑一趟"，而不是"角色死了"。丢蛋已经足够痛（一局 3-8 分钟白干），再加死亡惩罚会让玩家不敢贪——而"敢贪"正是这个游戏要的东西。

---

## 六、养成反哺：让循环闭合（不能断的那一环）

如果养成只是"看着它长大"，外循环就断了。必须让**养大的伙伴回过头来改变"偷"的方式**：

```
偷蛋 → 孵化 → 养成 → 伙伴陪同出击 → 偷到更贵的蛋 → 更稀有的伙伴 → 更难的巢
```

伙伴提供的是**被动修正，不是代替玩家操作**：

| 伙伴（Tier） | 被动效果 | 克制的环境威胁 |
|---|---|---|
| 蜥蜴（T2 湿地） | 免疫毒气 | 湿地的毒气区 |
| 鹰（T3 崖壁） | 滑翔，高处无声落地 | 崖壁坠落 |
| 火蜥蜴（T4 火山） | 免疫高温 | 火山持续掉血 |
| 雪鸮（T5 极地） | 暴风雪中视野不减 | 极地遮蔽 |
| 深海龙（T6 深海） | 氧气消耗减半 | 深海倒计时 |
| 蝙蝠（T7 地下） | 回声定位，黑暗中显示守卫 | 地下全黑 |
| 幼龙（T8 高山） | 威压，低级守卫不敢靠近 | 高山守巢 |
| 星龙（T9 云端） | 自身负重减半 | 云端失重 |
| 宇宙龙（T10 星球环） | 环行星球 | 终局 |

**每一阶孵出的伙伴，恰好克制下一阶的威胁** —— 这是进阶链的驱动逻辑。

**设计原则：伙伴让"更贪"变得可行，而不是让游戏变简单。** 拿了影龙你还是会想多带一颗——循环继续转。

### 第二层抉择：偷回来的蛋，留着还是献祭？

如果蛋只能孵化，玩家会无脑全孵，基地阶段就变成过场。所以每颗蛋有三重去向：

```
偷回来的蛋 ──┬── 孵化 → 伙伴（当期战力，让这一阶更好偷）
             ├── 献祭 → 基因点（永久属性成长、解锁高阶巢穴）
             └── 收藏 → 图鉴（解锁巢穴门票）
```

**"养着"还是"吃了"** —— 留着 = 这一次好过；献祭 = 以后都好过，但这一次难。
这是继"再拿一颗还是走"之后的**第二层贪心抉择**，让基地阶段也是决策而不是过场。

→ 完整兑换率见 [03-进阶与兑换体系](./03-进阶与兑换体系.md) §3、§4

## 七、单局节奏（目标体感）

| 指标 | 目标值 |
|---|---|
| 单次出击时长 | 3 - 8 分钟 |
| 一个巢的蛋位 | 3 - 6 个 |
| 玩家典型携带 | 2 - 3 颗（满上限是冒险行为） |
| 孵化时长 | 现实 2 - 6 分钟（可加速） |
| 成长到成年 | 3 - 5 次出击的喂养量 |
| 一个"完整循环" | 约 15 - 20 分钟 |

## 八、为什么这个循环能留住人（自查）

| 留存钩子 | 本作对应 |
|---|---|
| 短周期反馈 | 每次出击 3-8 分钟就有结果（拿到/丢光） |
| 技巧可提升 | 记路线、控制节奏、判断贪心上限，都是玩家自己的进步 |
| 长线目标 | 图鉴收集、稀有品种、巢穴解锁 |
| 不可预测性 | 蛋的活性、守卫巡逻的随机扰动 |
| Build 空间 | 带什么伙伴 + 什么装备 = 不同偷法（潜行流 / 强抢流 / 速度流） |
| 沉没成本 | 孵了一半的蛋（保护欲） |
