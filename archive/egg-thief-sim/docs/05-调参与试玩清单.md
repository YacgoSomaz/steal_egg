# 05 · 调参与试玩清单

> 这份文档存在的唯一理由：**守卫视野 240px / 70°、抓蛋 1.5s、警戒 15/s 这类数字，用数学推不出来。**
> 在拿到真人手感之前，整套进阶体系（10 生态阶 × 40 品种 × 属性成长）都是建在假设上的。
> 所以先把「调数值」这件事变得足够便宜。

---

## 1. 实时调参面板

游戏内按 **T** 打开面板，右上角。

| 键 | 作用 |
|---|---|
| `T` | 开 / 关面板 |
| `1` – `7` | 选中要调的那一行 |
| `,` | 减小（不用左方向键，那会带着人物一起走） |
| `.` | 增大 |
| `R` | 全部还原到本关基准 |
| `P` | 把当前配置打成一行日志输出 |

可调项：

| # | 参数 | 默认 | 说明 |
|---|---|---|---|
| 1 | 守卫视野距离 | 240px | **最该先调的一个** |
| 2 | 守卫视野角度 | 70° | 太宽就没法绕后 |
| 3 | 被看见警戒/秒 | 15 | 决定「被发现后还能不能跑」 |
| 4 | 守卫追击速度 | 115（T1） | 随生态阶变化，不写进存档 |
| 5 | 玩家跑速 | 180 | |
| 6 | 玩家蹲行速度 | 105 | 必须 > 守卫巡逻速度才绕得了后 |
| 7 | 抓蛋读条 | 1.5s | 最脆弱的 1.5 秒 |

调完的值自动存 `user://tune.json`，重启不丢（第 4 项除外——它的基准在 `egg_db.gd` 的生态阶表里，存成绝对值会把十阶难度拍平）。

---

## 2. 试玩时请回答的 6 个问题

不用长篇大论，一句话一个答案就行。

1. **守卫是不是瞎得离谱？** 站在蛋旁边不动，守卫多久发现你？
2. **被发现之后跑得掉吗？** 还是必死？还是随便跑跑就甩脱了？
3. **抓蛋的 1.5 秒紧张吗？** 还是纯粹在等读条？
4. **蹲走有用吗？** 还是全程按住 Shift 无脑跑？
5. **背 4 颗蛋 vs 背 1 颗，体感差别明显吗？**（负重系数 0.95 / 0.85 / 0.70 / 0.55）
6. **警戒条涨得舒服吗？** 静立 −4/s 的平复速度够不够快？

## 3. 快捷键速查

| 键 | 作用 |
|---|---|
| 方向键 | 移动 |
| `Shift` | 蹲走（噪音 0.5/s，跑步是 3.0/s） |

| `Q` | 放下一颗蛋 |

| `[` `]` | 切换生态阶（快速看十阶地形差异） |
| `T` | 调参面板 |

## 4. 调试面板（基地界面下方）

- 解锁全部生态阶
- +100 基因点
- 属性拉满
- 给 5 颗蛋
- 清空存档

**建议路线**：农场 T1 偷鸡蛋确实没劲。直接用调试面板解锁全部阶位，跳到 T8 高山龙巢 / T10 星球环，先确认「高阶玩起来爽不爽」，再回头调 T1 的新手体验。

## 5. 本轮已落地（v0.4）

- **每阶伙伴被动**：T2 免疫毒气 → T3 免疫强风 → T4 免疫高温 → T5 暴风雪视野 → T6 氧气减半 → T7 黑暗视觉 → T8 威压（守卫追击 −20%）→ T9 负重减半 → T10 宇宙龙全面免疫
- 基地「伙伴」栏现在会显示当前伙伴的被动说明，鼠标悬停可看每个候选的效果
- 守卫追击速度表重算：115 → 190（旧值 70–126，玩家是守卫的 2.57 倍，「速度决定跑不跑得过」这条完全失效）
