# 偷蛋长跑 · egg-runner

2.5D 无限跑道偷蛋跑酷 + 数值养成。Godot 4.7.2 · GDScript。

> 🤖 **如果你是接手这个项目的 AI → 先读 [`HANDOFF.md`](HANDOFF.md)**
>
> 里面有完整的设计推演、四轮真人试玩记录、所有踩过的坑和待办清单。
> 直接改代码大概率会重复踩坑。

---

## 玩法

一条越跑越危险的跑道，沿途怪物在沉睡。

1. 偷走它们的蛋 → 怪物**延迟一段时间**后苏醒（延迟长短 = 你的隐蔽属性）
2. 被追上 → 抢回最贵的一颗蛋 + **速度永久 ×0.97**
3. 带着蛋跑回起点才算数
4. 蛋养进农场产钱 → 钱买跑鞋 / 锻炼 / 披风 / 喷气 → 变得更快
5. 更快 → 起始阶位更深 → 偷更贵的蛋 → 螺旋上升

## 快速开始

```bash
"H:/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64.exe" --path . --resolution 1280x720
```

（引擎是便携版，注意真 exe 在"看起来像 exe"的目录里面）

无窗口自检：

```bash
"H:/.../Godot_v4.7.2-stable_win64.exe" --path . --headless --main-scene res://scenes/main.tscn --jump 900 --diag
```

详细环境说明见 [`docs/05-环境与运行手册.md`](docs/05-环境与运行手册.md)。

## 操作

| 键 | 作用 |
|---|---|
| `W/A/S/D` | 移动 |
| `E` | 偷蛋（读条 1.2s，期间不能动） |
| `Shift` | 蹲行（偷蛋波及半径减半） |
| `R` | 折返撤离 |
