# 偷蛋长跑 · egg-runner

2.5D 无限跑道偷蛋跑酷 + 数值养成。Godot 4.7.2 · GDScript。

> 🤖 **如果你是接手这个项目的 AI → 先读 [`HANDOFF.md`](HANDOFF.md)**
>
> 里面有完整的设计推演、四轮真人试玩记录、所有踩过的坑和待办清单。
> 直接改代码大概率会重复踩坑。

---

## 玩法

一条越跑越危险的跑道，沿途怪物在沉睡。

1. 偷走它们的蛋 → 怪物**延迟一段时间**后苏醒（延迟长短 = 你的隐蔽属性）
2. 被追上 → 抢回最贵的一颗蛋 + **速度永久 ×0.97**
3. 带着蛋跑回起点才算数
4. 蛋养进农场产钱 → 钱买跑鞋 / 锻炼 / 披风 / 喷气 → 变得更快
5. 更快 → 起始阶位更深 → 偷更贵的蛋 → 螺旋上升

## 操作

| 键 | 作用 |
|---|---|
| `W/A/S/D` 或 方向键 | 移动（**跟着视角走**：按 W 永远是"往画面里走"） |
| **鼠标** | 自由转视角（滚轮拉远近 3–24） |
| `E` | 偷蛋 / 在摊位前买东西（读条 1.2s，期间不能动） |
| `Shift` | 蹲行（偷蛋波及半径减半） |
| `Tab` | 释放 / 收回鼠标 |
| `ESC` | 释放鼠标；再按一次进详细管理面板 |

## 一个场景，不分里外

撤离线后面**直接就是农场和店铺**——扛着蛋跑回来，转身走两步就能升级，
还能看见自己养的生物在栏里晃。不再需要切场景。

六个摊位：锻炼 / 跑鞋 / 披风 / 喷气 / 入农场 / 卖蛋。

**撤离线是安全线**：越过它就自动入库，**追兵到此回头，不会再追进农场**。
地面有发光横线标着，跨线时会有提示。
