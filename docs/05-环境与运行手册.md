## 二、启动与自检

### 正常启动

```bash
cd <仓库根>
"H:/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64.exe" --path . --resolution 1280x720
```

### 无窗口自检（**改完代码先跑这个**）

```bash
# 默认主场景（农场）
"H:/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64.exe" \
    --path . --headless --quit-after 180

# 单独验证跑道场景
"H:/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64.exe" \
    --path . --headless --main-scene res://scenes/main.tscn --quit-after 180
```

`--quit-after N` = 跑 N 帧后自动退出。比开窗口快得多，能抓出绝大多数运行时错误。

### 自定义调试参数（写在 `main.gd`，依赖 `OS.get_cmdline_args()`）

| 参数 | 作用 |
|---|---|
| `--jump <距离>` | 直接跳到指定距离，省得手动跑 |
| `--diag` | 打印生成结果自检 |

```bash
"H:/.../Godot_v4.7.2-stable_win64.exe" --path . --headless \
    --main-scene res://scenes/main.tscn --jump 900 --diag
```

**健康输出**（出现 `[自检]` 且无 ERROR 即通过）：
```
[自检] 起点阶 T2 ｜ 距离 900 m ｜ 当前阶 T4 ｜ 沉睡怪 84 只 ｜ 蛋 84 颗
       ｜ 阶位分布 { 2: 5, 1: 1, 3: 13, 4: 6, 5: 18, 6: 25, 7: 16 }
```

不同距离的预期结果：

| `--jump` | 起点阶 | 当前阶 | 说明 |
|---|---|---|---|
| 900 | T2 | T4 | 已验证 ✓ |
| 20000 | T9 | T9 | 已验证 ✓ |

> ⚠️ **注意**：`--jump` 只把玩家传送过去，**怪物列表在传送之前就生成完了**。
> 所以不管跳多远，阶位分布始终是 `{1..7}`，高阶建模代码不会被执行到。
> 要逐阶验证建模，用下面的 `--gallery N` 或 `--script tools/model_test.gd`。

### 陈列模式：逐阶看怪物外形

```bash
# 从 T1 开始，按 1-9 / 0 跳阶，[ ] 前后翻，ESC 回农场
"H:/.../Godot_v4.7.2-stable_win64.exe" --path . --resolution 1280x720 \
    --main-scene res://scenes/main.tscn --gallery

# 从指定阶位开始（headless 下也能用来逐阶验证接线）
"H:/.../Godot_v4.7.2-stable_win64.exe" --path . --headless \
    --main-scene res://scenes/main.tscn --gallery 10 --quit-after 90
```

### 商店自检：把六个摊位各买一遍

```bash
"H:/.../Godot_v4.7.2-stable_win64.exe" --path . --headless \
    --main-scene res://scenes/main.tscn --shop --quit-after 200
```

会给一笔假钱，把 锻炼/跑鞋/披风/喷气/入农场/卖蛋 各买一遍，打印扣钱与属性变化。


打印每阶的网格数 / 腿数 / 体节数 / 翼数 / 是否浮游。

## 三、操作方式

| 键 | 作用 |
|---|---|
| `W/A/S/D` 或 方向键 | 移动 |
| **鼠标** | 自由转视角（第三人称环绕） |
| **滚轮** | 拉远 / 拉近 |
| `E` | 偷蛋；在摊位前则是买东西 |
| `Shift` | 蹲行（偷蛋波及半径 12 → 6） |
| `Tab` | 释放 / 收回鼠标 |
| `ESC` | 释放鼠标；再按一次进详细管理面板 |

### ⚠️ WASD 曾经完全用不了

原因是直接用内置的 `ui_left` / `ui_right` / `ui_up` / `ui_down`，
而 **Godot 4 里这四个默认只绑方向键、不含 WASD**。

现在 `project.godot` 里定义了 `move_left/right/forward/back` 四个动作，
WASD 和方向键都绑上（字母键用 `physical_keycode`，换键盘布局也不会失灵）。

自检：
```bash
"H:/.../Godot_v4.7.2-stable_win64.exe" --path . --headless --script res://tools/input_test.gd
```

### 摊位交互必须用"按下"边沿

按 E 买装备不能用 `Input.is_key_pressed(KEY_E)` 轮询 ——
站在摊位前按住 E 会**每帧买一次**，一秒钟把金币清空。
现在走 `_input()` 里的按下事件，置一个 `_want_interact` 标志，消费后立即清掉。

## 四、调试技巧

### 快速跳到高阶内容

农场 T1/T2 起步确实没劲。**用 `--jump` 直接跳**：
```bash
--main-scene res://scenes/main.tscn --jump 20000 --diag
```
或者临时改 `GameState` 的初始值（记得改回来）。

### 修改数值不用重启

`GameState` 是 autoload，数值都在 `scripts/core/game_state.gd` 顶部的常量区。
改完 `--headless` 跑一遍确认没报错，再开窗口。

### 常用排查顺序

1. `--headless --quit-after 180` → 有没有 ERROR
2. 有 ERROR → 看行号，通常是类型推断问题（见 `06-技术陷阱清单.md`）
3. 没 ERROR 但现象不对 → 加 `print()` 或 `--diag` 打印中间值
4. 涉及视觉/手感 → **必须开窗口让人玩**，headless 看不出来
