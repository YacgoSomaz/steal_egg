# 09 · 农场区、店铺与自由视角

> 用户原话：
> "我想加入鼠标自由视角，然后不分局外，撤离点后面就是可以升级的店铺
> 以及可以看到自己养的生物"

这一轮把「跑一趟 → 退出到另一个场景 → 买东西 → 再进去」这个被切碎的节奏
接成了一个连续的空间：**撤离线后面就是农场和店铺，走回去就行。**

## 一、布局

z 轴：跑道往 −Z 延伸，农场往 +Z 延伸。

```
   −Z  跑道（越远越危险）
        ⋮
   −12  ┊ ★ 安全线 SAFE_LINE（蛋入库 + 追兵回头，同一帧）
    −8  ┊ 「起点 / 撤离」地标
     0  ┊ 分隔带（深色地面 + 黄线）
    10  ┊ 六个摊位一字排开
    46  ┊ 畜栏中心，养着的生物在这儿游荡（半径 15）
    74  ┊ 围栏尽头
   +Z
```

摊位 x 坐标：`−18 / −10.5 / −3 / +4.5 / +12 / +19.5`

| 摊位 | 作用 |
|---|---|
| 锻炼 | `speed_level` ↑，乘算 ×1.09/级 |
| 跑鞋 | `shoe_level` ↑，加算 +2.5/级 |
| 披风 | `gear_cloak` ↑，苏醒延迟 ×1.15/级 |
| 喷气 | `gear_jet` ↑，开局爆发 ×1.25/级 |
| 入农场 | 仓库里所有蛋 → 农场，开始产钱 |
| 卖蛋 | 仓库里所有蛋 → 立刻变现 |

每个摊位是「台子 + 台面 + 招牌 + 悬浮文字标签」，标签实时显示等级/成本/当前效果。

## 二、自由视角相机

从「固定越肩」改成绕玩家的第三人称环绕。

| 参数 | 值 |
|---|---|
| 鼠标灵敏度 | `MOUSE_SENS = 0.0026` |
| 俯仰范围 | `−0.35`（几乎平视，看巨兽用）～ `1.15`（接近俯视） |
| 距离 | 3.0 ～ 24.0，默认 8.6，滚轮步长 0.9 |
| 看向点 | 玩家 + 1.3（胸口，不是脚底） |

相机位置 = `看向点 + (sin(yaw)·cos(pitch), sin(pitch), cos(yaw)·cos(pitch)) × 距离`

`yaw = 0` 时相机在 +Z（玩家背后），因为玩家朝 −Z。

**朝向每帧重算**：位置是 `lerp` 平滑过去的，朝向不能也跟着慢半拍，
否则转身时画面会"甩"一下。

**速度补偿照旧保留**：`camera_zoom(速度)` 仍然乘在距离上（封顶 3.5 倍），
FOV 仍然随速度撑开 —— 这是速度感的来源，不能被自由视角吃掉。

### ⚠️ 移动也必须跟着视角转

**这是第一版漏掉的一半，用户直接报了回来：**

> "人物不会随着我的视角改变而改变前进方向"

原来的移动是 `velocity = Vector3(input.x, 0, input.y) * sp` —— 纯世界坐标。
加了转视角之后这个式子一点没改，于是转了视角按 `W`，人物往世界 −Z 走，
画面上却是往旁边走。

✅ 换算逻辑在 **`scripts/core/move_math.gd`**（纯函数、零 autoload 依赖）：

```gdscript
var fwd   := Vector3(-sin(yaw), 0.0, -cos(yaw))   # 画面里的"前"
var right := Vector3( cos(yaw), 0.0, -sin(yaw))   # 画面里的"右"
dir = (right * input.x + fwd * (-input.y)).normalized()
```

`yaw = 0` 时结果和世界坐标完全一致，**没转视角时手感不变**。
`main.gd` 每帧把 `_cam_yaw` 喂给 `player.cam_yaw`（喂的是目标角，不是 lerp 后的角，更跟手）。

> 之所以单独开一个文件：`--script` 自检不能 `preload` 引用 autoload 的脚本
> （会无声退出），所以这段数学必须零依赖才能被断言守住。
> 8 个用例见 `tools/input_test.gd`。

## 三、安全线：农场是安全区

**追兵追到 `SAFE_LINE` 就必须回头，物理上也不许越线。**

这条线必须在三个地方同时生效，所以它是**一个常量**（`CreatureDB.SAFE_LINE = -12.0`）：

| 用处 | 位置 | 少了会怎样 |
|---|---|---|
| 蛋自动入库 | `main.gd _check_escape()` | 蛋带不回来 |
| 追兵放弃 | `creature.gd _tick_chase()` | **怪追进店铺门口撞人** |
| 追兵位置夹取 | `creature.gd _tick_chase()` | 高速怪一步跨过线 |

还有一条兜底：**抓取半径也卡在线外**。T10 的判定半径是 `1.9 × 4.6 = 8.7` 米，
不卡的话它能隔着撤离线把站在店门口的玩家抓住。

### 为什么这条线这么重要

用户报过两条听起来毫不相干的反馈：

> "我把蛋带回来了，然后我去卖蛋，**他说我没有蛋**"
> "**怪物都追到撤离点里面来撞我了**"

**其实是同一件事**：追兵跟着玩家越线 → 玩家在过线前最后一米被撞掉蛋 →
背包空了 → 过线时没东西入库 → 到摊位自然说"仓库是空的"。

**"卖蛋说没蛋"只是"怪追进家"的下游症状。**

> 教训：不要按用户给的**症状编号**逐个修，要去找**共同的上游**。

### 看得见的反馈

- 地面上有一条发光横线 + `安全线 · 过此线追兵回头` 的 Label3D
- 跨线时弹一次 `已进入撤离区——追兵到此为止，不会再追进来`
  （用 `_at_home` 记录上一帧状态，只在"刚跨过来"时弹）

## 四、畜栏里的生物

按 `GameState.farm` 重建，每只按黄金角 `i × 2.399963` 铺开，半径 `sqrt(i/n) × 15`，
摆得均匀又不呆板。

行为是「随机踱步」：走到一个目标点就换下一个，速度 `1.4 + tier × 0.06`。
站着不动打转看着像标本，走起来才像"这是我养活的"。

**性能**：每只二十来个网格，所以
- 上限 `MAX_PEN_CREATURES = 20`
- 玩家跑远超过 240 单位就整只 `visible = false` 并跳过逻辑

## 五、六个坑（都踩过）

### 1. 摊位交互必须用"按下"边沿，不能轮询

```gdscript
# ❌ 站在摊位前按住 E 会每帧买一次，一秒钟把金币清空
if Input.is_key_pressed(KEY_E):
    buy()

# ✅ 走 _input() 的按下事件，置标志位，消费后立刻清掉
func _input(event):
    ...
    KEY_E: _want_interact = true

func _handle_shop():
    if _want_interact:
        _want_interact = false
        ...
```

### 2. 购买成功却没有任何提示

```gdscript
# ❌ _after_buy 只是把消息收下了，interact 最后返回空字符串
if GameState.upgrade_speed():
    _after_buy("锻炼到 Lv%d" % ...)
...
return ""      # ← 提示永远不显示

# ✅ 用局部变量接住，最后统一返回
if not GameState.upgrade_speed():
    return _fail(...)
msg = "锻炼到 Lv%d" % ...
_after_buy(msg)
return msg
```

### 3. 失败提示写死了价格

`_fail` 里用了 `get_speed_cost()`，导致买跑鞋钱不够时提示的是**锻炼**的价格。
现在 `_fail(名称, 是否满级, 成本)` 三个参数都从调用方传进来。

### 4. 玩家分不清"蛋去哪了"

用户把蛋放进农场（开始产钱）之后，再去卖蛋摊位，看到的是"仓库是空的"，
**会以为游戏把他的蛋弄丢了**。

✅ 两条修法：
1. 卖蛋/入农场的牌子**同时显示两个数字**：`仓库 N 颗 ｜ 农场 M 只`
2. 空仓库的提示要**区分两种情况**：

```gdscript
func _empty_stock_msg() -> String:
    if not GameState.farm.is_empty():
        return "仓库空了——你的 %d 只都在农场产钱（每秒 +%.1f）。农场的取不回来，想要现金得去偷新的蛋"
    return "仓库和农场都是空的——先去跑道上偷几颗蛋回来"
```

> 一句笼统的"仓库是空的"，在玩家听来就是"我的东西没了"。

### 5. ⚠️ 自检把测试数据写进了玩家存档

`--shop` 自检会真的改 `GameState`，而购买流程里带 `SaveManager.save()`，
结果第一版直接把测试用的 **99 万金币**写进了玩家存档。

**第一版修法是"开头快照、结尾还原"，但这不够** ——
中途报错、进程被杀、或者玩家**正在同时玩**，还原都没机会执行。

✅ 最终解法：**`SaveManager.test_mode`**。自检一开始就打开，此后 `save()` 直接 return。

```gdscript
var test_mode := false
func save() -> void:
    if test_mode:
        return
```

> **验证方法**：跑完自检后 `diff` 存档文件，确认逐字节没变。
> 这是唯一可信的验证——"我以为我还原了"不算。

### 6. 诊断指标被兽栏污染

`--diag` 的"最近怪距离"一度永远是 `0 m`。
原因：兽栏里养的怪也在 `creatures` 组里，而兽栏在 z≈46，
`max(0, -46) = 0`，于是"最近怪"被算成了 0。

✅ `_diag()` 里跳过 `_display == true` 的怪（它们不睡、不追、不在跑道上）。

> **教训**：**一个会骗人的指标比没有指标更危险。**
> 它会让你以为"首怪距离修好了"，其实什么都没测到。
